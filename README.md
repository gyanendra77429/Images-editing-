# AuraVideo Studio

A personal aesthetic photo and video editing studio.

## Features

- Six signature color-grading presets
- Photo and video import
- Eleven adjustment controls
- Signature Aesthetic Prompt
- Original and edited comparison
- Photo export
- Browser-supported video export
- Local browser processing
- Responsive interface

## GitHub Pages Setup

1. Upload all project files to the repository root.
2. Open Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the main branch.
6. Select /(root).
7. Click Save.

Wait for deployment and open the GitHub Pages URL.

## Browser Compatibility

Video export depends on browser support for MediaRecorder,
canvas capture, and audio capture.

Some browsers export WebM rather than MP4.

The app processes selected media locally in the browser.
